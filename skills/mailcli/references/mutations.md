# Mailbox mutations and synchronization

- Direct IMAP mark/move/copy/delete need current store identity/UIDVALIDITY/server_truth; local-only/degraded/ambiguous/duplicate-ID targets stop. Cross-process account lock: 30 s; busy is no-effect/retryable. Unavailable lock: repair named directory/permissions, reads remain available. Send probes setup nonblockingly before credentials/SMTP; holder is valid setup, not acquired ownership. MAILCLI_IMAP_MUTATION_LOCK=off allows only process-local ordering; reads/hydration unlocked.
- Before command write: COPY/MOVE not_started, observed source UIDVALIDITY retained, tentative COPY cleared; no post-dispatch reconciliation. Correct validation first; obey next.do for timeout/cancel, no automatic canceled restart. Partial write/missing reply/effects: inspect both locations before further mutation.
- MOVE/delete-to-Trash: one existing account lock covers source proof, destination guard and effect checks. Existing/ambiguous destination stops without deleting source. Authenticated capabilities choose native or fallback; unknown discovery stops, native NO/BAD never triggers COPY. Native OK needs source absence plus verified COPYUID/destination or one exact independent Message-ID; missing proof stays imap_move_outcome_unknown. Message-ID-less native needs generation-bound UID/COPYUID; fallback needs independent Message-ID.
- Fallback checks required Deleted permission before COPY; unsupported emits zero COPY. Missing COPYUID needs destination proof before STORE. Verify Deleted before UID EXPUNGE and source absence afterwards; unsupported UID EXPUNGE defers, never plain EXPUNGE. Later failures retain COPY/actual flags in message_state/delete_result; inspect both locations, no blind COPY/STORE. Flags are pre-expunge, summaries cached.
- Mark: server_truth.flags_state=observed, actual_flags, flags_source=STORE/FETCH; observed empty confirms no flags. Mismatch/post-STORE missing/unknown retains failed evidence. Unverified summaries cached; inspect instead of STORE replay. Batch unknown/missing=uncertain.
- [Batch](output-and-recovery.md) preserves evidence; unknown=uncertain/no replay. Delete --confirm; move/copy destination mailbox ref.
- Junk true: add $Junk/remove $NotJunk; false inverse. Read/skip no-op/check PERMANENTFLAGS; verify removal before addition. Bare Junk/NotJunk unrelated; both standardized flags mean neither classification. Unsupported retains permissions/state; partial retains verified phase. Inspect outcome/effect_certainty: known partial/unsupported failed, unknown uncertain; no blind replay.
- `mailcli sync --check`: IMAP local/server identities; complete + counts_match true means equal counts, skipped entries are not failures, differing counts close after Mail.app synced. `sync` without `--check`: request Mail sync after a live Apple Events check.
- Verify with `mailcli messages state --ref MSG_REF`: bounded read-only FLAGS; data.state separates server_flags/observed-or-missing server_state from stale local_index_flags, reports flags_agree.
