# MailCLI Agent Rules

## Release Authority

- The user is the sole release authority.
- Never create, push, or delete git tags or GitHub releases without an explicit
  user request that names the exact version and action.
- Never bump version strings in code, docs, filenames, or release artifacts
  without an explicit user instruction.
- Never speak of a new version number unless the user raised it first.
- Committing code is fine; tagging, publishing, and version naming are not.
